# Madhu-Marga 🐝
AI Guided Digital Beekeeper Assistant

## 📌 Problem Statement
Honey bees are very important for pollination and agriculture. Many beginner farmers lose bee colonies because they cannot identify hive problems such as low activity, pests, temperature imbalance, or queen absence.

Madhu-Marga helps farmers monitor hive health and provides AI-based suggestions for better hive management and honey production.

---

## 📱 Project Description
Madhu-Marga is an Android application developed using Kotlin and Jetpack Compose. The app acts as a digital beekeeper diary where users can:

- Register bee hives
- Track honey harvests
- Log hive inspections
- Monitor hive activity
- Receive AI-based intervention alerts
- Maintain flora blooming information
